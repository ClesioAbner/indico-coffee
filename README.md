# Índico Coffee 

Landing page de uma cafetaria conceptual inspirada na cultura urbana e no estilo de vida de Maputo, Moçambique.

Este projecto surgiu como uma oportunidade para aperfeiçoar as minhas competências em **UI/UX Design e Frontend Development**, explorando uma experiência digital moderna, elegante e interactiva.

##  Funcionalidades

- Design moderno, responsivo e adaptado a dispositivos móveis.
- Animações interactivas com Motion.
- Copo animado que acompanha o scroll da página.
- Menu dinâmico com categorias e produtos.
- Carrosséis interactivos.
- Secção de perguntas frequentes.
- Navegação intuitiva e acessível.
- Optimização para motores de busca (SEO).

##  Tecnologias usadas

- HTML5
- CSS3
- JavaScript
- Motion
- Git & GitHub Actions

## Objectivo do projecto

Aprofundar conhecimentos em UI/UX Design, melhorar a atenção ao detalhe visual e desenvolver interfaces que conciliem estética, funcionalidade, acessibilidade e experiência do utilizador.
